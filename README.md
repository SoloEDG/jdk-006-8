# 雾港来电 · 午夜频率

## 安装

使用 Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## 视觉调查路径

听不清背景声时，可在右侧切换到「视觉调查」标签：钟声、雾笛与电流会跟随播放按时间逐项呈现为带方位与节奏（短促 / 持续、来自哪一侧）的视觉事件。

- 事件只有在连续播放越过其时刻时才会点亮；直接拖动进度条跳到未呈现处不算已观察。
- 全部事件呈现后，通过比较次数、节奏或方位作答，答对即取得与直接收听完全相同的正式线索，重复取得不会重复计数。
- 收听与视觉两条路径的进度各自保留、互不覆盖，并随调查存档一起保存、导入后可继续。
- 系统开启「减少动态效果」时，动画退化为静态逐项呈现，仍可完成全部比较与作答。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8086 。可通过 PORT 环境变量修改端口。
